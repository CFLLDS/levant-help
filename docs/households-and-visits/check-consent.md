# Check consent

**Tab: Consent & evidence**

This tab lists every consent held for your households: the case, the consent state, how it was signed, the date signed, the date it runs to, the data service status and the date withdrawn if it has ended.

The line at the top tells you how many consents are **not registered with the data service**. For those homes the resident has signed but no readings are arriving. Check the case, and if it does not clear within a day, contact support.

Consent runs for twelve months from the date signed. Plan a review visit before the **Runs to** date.
