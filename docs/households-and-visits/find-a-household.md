# Find a household and read its case

**Tab: Cases**

## Find the household

1. Select the **Cases** tab.
2. Type a name, a postcode or a case reference (for example `EW-CASE-000123`) in the **Search** box and select **Search**.
3. Use the filter buttons under the search box to narrow the list. Each button shows a count.
   - **All**: everything the search found.
   - One button for each status in the list, for example **Live** or **Consent given**, busiest first. Only statuses that are actually in the list get a button.
   - Select the highlighted button again to clear the filter.
4. Select the household in the list. Its case opens on the right.

Withdrawn and cancelled cases are listed too, so you can find one to remove its data. Use the status buttons to hide them. The list shows the first 100 matches, so narrow your search if you cannot see the one you want.

## What the case shows

| Field | Meaning |
|---|---|
| Status | Where the case is in its journey, for example consent given or live |
| Phone and Preferred contact | How the resident asked to be contacted. Always use their preferred route first |
| Next visit, or Last appointment | The next booked visit, with date, time, type and adviser. When nothing is still to come it says **Last appointment** and shows the most recent one. "None booked" means there has never been one |
| Appointment letter | Whether the letter has been delivered |
| Adviser visits | How many visits have been made |
| Consent | One row per meter. Shows the state (given or withdrawn), how it was signed, the consent statement version, the date signed, the date it runs to, and whether the data service has confirmed it |
| Visits | Every visit for this household with its date, type and outcome |

### How consent was signed

| Shown as | Meaning |
|---|---|
| QR code | The resident scanned the QR code on their appointment letter |
| Unique code | The resident typed in the code from their letter |
| Adviser assisted, on the display | An adviser helped the resident in the home, using the in-home display |
| Recorded by an adviser | An adviser recorded the resident's consent for them |

### Data service column

| Shown as | Meaning |
|---|---|
| Confirmed | Registered. Readings will arrive |
| not confirmed | Signed, but not yet confirmed by the data service. No readings yet |
| Not accepted | The registration was rejected. Contact support |
| withdrawn | Consent has ended. Readings have stopped |

## What you can do from the case

| Button | What it does |
|---|---|
| **Book a visit** | See [Book a visit](book-a-visit.md) |
| **Print brief** | Energy Confidence Dorset cases only. Opens a one-page visit brief to print and take on the visit |
| **Generate letter** | Makes the appointment letter with its QR code and unique code. Once a letter exists the button says **Re-issue letter**, and **View current PDF** opens the latest one. Re-issuing stops any older printed copy from working, and the case warns you if the letter on file is out of date |
| **Handyperson referrals for this case** | Opens the Handyperson tab for this household. See [Refer a job to the handyperson](handyperson-referral.md) |
| **Withdraw, cancel or remove…** | See [End a case](end-a-case.md). If there is nothing to end yet, the button says **Nothing to end on this case yet** |
