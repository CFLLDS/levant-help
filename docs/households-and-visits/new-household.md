# Bring a new household on board

**Tab: New household**

This is a guided journey shown as a progress line across the top: Find the home, Check the meter, Create the case, Book the visit, Letter & code, Adviser visit, Consent, Live.

Once the meter is checked, the form below the progress line takes over with its own numbered steps, from **Step 1 · Create onboarding case** to **Step 7 · Activate live data**. The sections below follow the progress line and give the form's step name alongside.

The usual route is to book a visit for a later date. If you are already standing in the property, say so when you book the visit and record it there and then.

## Before you start: Onboard into

If you work for more than one programme, the first thing on the tab is **Onboard into**. Choose the customer account the household belongs to, for example Energy Confidence Dorset. If you only have one, the choice is made for you and the box does not appear.

Once the case has been created, the choice is fixed for that household.

## Find the home

1. Type the **Postcode** and select **Find addresses**.
2. Pick the address from the list.

Always pick from the list if you can; do not type the address by hand. It lets the system tell the difference between a wrong address and a meter it cannot see.

## Check the meter

The address is filled in for you: **House number, flat number, or building name**, **Address line 1 (optional)** and **Town (optional)**. You can add the **Meter serial number (optional, evidence only)** if you have it.

Select **Check eligibility**. The system asks the smart meter data service whether it can see a smart meter at the property.

| Result | What to do |
|---|---|
| Smart meter found and confirmed | Carry on |
| Only one supply comes back (for example electricity but not gas) | Carry on. The rest is picked up once the household has given consent |
| More than one smart meter | Tick every meter point to bring on board and select **Continue with selected meter**. Electricity and gas can go on one case |
| The property cannot currently proceed | Do not create a case or print a letter. Check the address, then contact support |
| Temporary problem talking to the data service | Wait a few minutes and select **Retry check** |

### If the address cannot be found

1. Select **Enter the meter number instead**.
2. Type the **Postcode** and the **Meter number (from a recent bill or In Home Display)**, then select **Check this meter**.
3. If you do not have the number, select **Upload a bill** and choose a photo or PDF of a recent bill (up to 10 MB), then **Upload bill**. Check the number it reads and select **Use this number**.

**Reset** clears the form. You are asked **Start this check again?** first. Select **Keep what I have** to carry on.

## Create the case (Step 1 · Create onboarding case)

1. Enter the **Resident name**, **Resident phone** and **Resident email**. Each is optional, but you need a way to reach them.
2. Choose the **Preferred contact method**.
3. Choose the **Delivery partner**.
4. Choose **How did this household come to us?**
5. Check the property address and postcode.
6. Select **Create case**. The case is given its EW-CASE reference.

## Book the visit (Step 2 · Book appointment)

Answer **Is this visit being arranged for later, or happening now?**

- **Arranging a visit for a later date.** Choose the **Appointment date & time** and the **Adviser name**, add any **Notes**, and select **Book appointment**. The next step makes the letter the resident receives. See also [Book a visit](book-a-visit.md).
- **I am at the property now.** No slot is booked. Select **Record the visit** to go straight to recording it. It appears in the diary at the time it actually happened.

## Letter & code (Steps 3 and 4)

1. **Step 3 · Generate appointment letter.** Choose the **Delivery method** (post, email or hand delivered) and select **Generate appointment letter**. The letter carries a QR code and a unique code the resident uses to give consent. Making a new letter stops any older printed copy from working.
2. **Step 4 · Record delivery evidence.** Once it has gone, record the **Delivery status**, the date, and the **Evidence type**, for example proof of postage or a hand-delivered log. Select **Record delivery evidence**.

## Adviser visit (Step 5 · Record adviser visit)

Choose the **Visit status** (completed, no access, declined, rescheduled, or in progress), the date and time, and the **Adviser name**, add **Notes**, and select **Record adviser visit**.

## Consent (Step 6 · Capture resident consent)

The resident gives consent in one of four ways:

| Consent route | When |
|---|---|
| QR code (from the letter) | The resident scans the code on their letter |
| unique code (from the letter) | The resident types the code from their letter |
| assisted IHD | You help them in the home, using the in-home display |
| manual attestation (adviser witnessed) | You witness and record their consent |

Choose the **Consent status**: given, refused, or pending if the resident wants more time. Select **Capture consent**.

## Live (Step 7 · Activate live data)

1. Check the **Move-in date**. Readings are fetched from this date.
2. Leave **Pull history** on **yes (recommended)**, so the past year of readings is collected.
3. Leave **Electricity frequency** and **Gas frequency** as they are unless support has told you otherwise.
4. Select **Activate**.

The data service confirms the consent and readings start to arrive. This can take a day or two. Check progress on the [Consent & evidence](check-consent.md) tab.
