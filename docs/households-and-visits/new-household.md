# Bring a new household on board

**Tab: New household**

This is a guided journey with eight steps, shown as a progress line across the top: Find the home, Check the meter, Create the case, Book the visit, Letter & code, Adviser visit, Consent, Live.

The usual route is to book a visit for a later date. If you are already standing in the property, say so at step 2 and record the visit there and then.

## Step 1: Find the home

1. Type the **Postcode** and select **Find addresses**.
2. Pick the address from the list.

Always pick from the list; do not type the address by hand. It lets the system tell the difference between a wrong address and a meter it cannot see.

## Step 2: Check the meter

The address is filled in for you. You can add the **Meter serial number** if you have it. It is optional and kept as evidence only.

Select **Check eligibility**. The system asks the smart meter data service whether it can see a smart meter at the property.

| Result | What to do |
|---|---|
| Smart meter found and confirmed | Carry on to step 3 |
| Only one supply comes back (for example electricity but not gas) | Carry on. The rest is picked up once the household has given consent |
| More than one smart meter | Tick every meter point to bring on board. Electricity and gas can go on one case |
| The property cannot currently proceed | Do not create a case or print a letter. Check the address, then contact support |
| Temporary problem talking to the data service | Wait a few minutes and try again |

If the meter cannot be found automatically you can upload a photo or scan of a recent bill (up to 10 MB) and the meter number is read from it. If it cannot be read, type the number in from the bill.

## Steps 3 to 8

!!! note "This part of the guide is being completed"
    The steps below are an outline. Full instructions with screenshots will follow.

3. **Create the case.** Enter the resident's name, contact details and preferred contact route. The case is given its EW-CASE reference here.
4. **Book the visit.** The same as [Book a visit](book-a-visit.md).
5. **Letter & code.** Produces the appointment letter with a QR code and a unique code. Generating a new letter stops any older printed copy from working.
6. **Adviser visit.** Record the visit and its outcome.
7. **Consent.** The resident signs by QR code, by unique code, or with the adviser's help.
8. **Live.** The data service confirms and readings start to arrive.
