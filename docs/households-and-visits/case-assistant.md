# Ask the assistant

**Button: Assistant, at the edge of the page**

The case assistant answers questions about a case and about how to use this page. It is read only: it explains and points you to the right place, but it never books, sends or changes anything.

1. Select **Assistant**. The **Case assistant** panel opens.
2. Pick one of the suggested questions, or type your own and select **Ask**. If a case is open, the question is about that case. Otherwise, name the case by surname, postcode or reference.
3. **Expand** makes the panel wider, and **Narrow** puts it back.
4. **New conversation** starts afresh.

Every question is logged to your name.

The assistant can be wrong. Check anything important on the case itself before you act on it, and contact support if something does not add up.
