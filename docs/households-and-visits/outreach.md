# Work through the outreach list

**Tab: Outreach**

This tab is for Energy Confidence Dorset outreach. It lists every household from the Charitylog list. Names and addresses come from Charitylog and are corrected there; the next sync brings the change across.

The usual order of work is: send a letter, wait a week, then ring. Calls due appear on [My calls today](my-calls-today.md).

## Find households

Use the filters, then select **Show**.

| Filter | Use it to |
|---|---|
| **Status** | Show one stage, for example Case created or Letter sent |
| **Kind** | Smart meter, Advice only, or Needs review |
| **Tier** | Priority 1, 2 or 3 |
| **Postcode district** | For example DT1 |
| **Last Age UK contact** | Under 3 months, 3–12 months, over 12 months, or unknown |
| **Screening** | **Ready to contact**, or **Greyed: waiting for the check** |
| **No working contact details** | Households with no usable phone or address in Charitylog |

Select a case reference to open the household. See [A household before consent](../giving-advice/before-consent.md).

**Export for Charitylog** downloads the list in a form Charitylog can import.

## Greyed-out households

Some rows are greyed out. These households are on hold: they get no letter and do not appear on anyone's call list. The status says why.

| Shown as | Meaning |
|---|---|
| Waiting for the deceased and gone-away check | The check has not come back yet |
| Possible death: check before any contact | The check suggests the client may have died. Check Charitylog before anyone makes contact |
| May have moved: check before any contact | The check suggests the client may have moved |
| On hold: CRM-only client, waiting for the steering committee | Known only from Charitylog. The steering committee decides how these households are contacted |
| On hold: someone in this household has died | An adviser decides if and when to make contact |

Two labels mean the household is clear to contact:

| Shown as | Meaning |
|---|---|
| Seen by Age UK this month or next: OK to contact | Has a footcare or home support appointment around now |
| Screened: OK to contact | The check found nothing |

Other tags on a row: **Also a Nourish client**, **Also a footcare client**, **Over a year** (no Age UK contact for more than a year), and **No working contact details: check Charitylog**.

## Send one letter

The **Letter** button on a row prints the first letter to that household, signed by the chief executive.

1. Select **Letter**. The letter opens as a PDF in a new tab.
2. Print it at 100% scale on A4 and post it.

The first print moves the household from **Case created** to **Letter sent**, and its follow-up call becomes due a week later. The row then shows the letter's reference and date, and the button says **Print letter again**. Printing again does not change anything else.

There is no Letter button for greyed-out households, households that have said no, or households without a full postal address.

## Send letters in a batch

1. Set the filters for the households you want to write to.
2. Fill in **Write-to list: how many** and select **Make write-to list**.
3. Read any warning. It points at households to check in Charitylog first.
4. Select **Download mail merge** and produce the letters.
5. When they have been posted, fill in **Letter date** and select **Mark written**. Large lists are marked in stages, and the page shows how many are done.

If the page says some letters weren't recorded, select **Mark written** again.

## Assign or re-tier

Tick the households first.

- To give them to an adviser, type the adviser's email in **Assign ticked to (email)** and select **Assign**.
- To change their priority, choose **Set tier** and select **Re-tier**.

## Change a status

Use the controls at the right of the row. The table scrolls sideways if they are off the edge.

1. Choose **Change status…**
2. If it asks for one, choose a **Reason (optional)**. For example, a returned letter can be **Gone away** or **Addressee unknown**.
3. Select **Save**.

When a wrong phone number has been corrected in Charitylog, select **Number fixed in Charitylog**. The household goes back onto the call list.

Every reason is a fixed choice. There is nowhere to type notes, so no health or care details are kept here.
