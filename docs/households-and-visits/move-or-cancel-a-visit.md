# Move or cancel a visit

**Tab: Visit diary**

## Find the visit

1. Select the **Visit diary** tab.
2. Set **From** (the first day you want to see) and **Days** (how many days ahead). The default is 14 days from today.
3. Choose a **Status**: Booked and rearranged, All including cancelled, Completed, or No access.
4. Choose a **Type**: Assessments and reviews, Assessments only, or Reviews only.
5. Select **Show**.
6. Switch between **List**, **Week** and **Month** views. Use the name buttons to show one adviser's visits only.

Each visit shows its time, type, household, address, adviser and status. The statuses are Booked, Moved, Done, Cancelled and No access.

## Move a visit

1. Select **Move** next to the visit.
2. Pick the **New date** and **New time**.
3. Type the **Reason**, for example "Resident asked to move it". The reason is saved against the appointment, so the record shows what happened.
4. Select **Move the visit**. To leave it alone, select **Keep as it is**.

## Cancel a visit

1. Select **Cancel** next to the visit.
2. Type the **Reason**.
3. Select **Cancel the visit**. To leave it alone, select **Keep as it is**.

Cancelling a visit does not close the case. To close a case, see [End a case](end-a-case.md).
