# Return a call back

**Tab: Call backs**

People who ring the Energy Confidence phone line (01305 231380) or fill in the website form can ask to be called back. Most will be new and will not have a case yet.

1. Select the **Call backs** tab. It opens on **Waiting for a call back**.
2. Each row shows when they asked, their name, contact details, what it was about and how the request arrived.
3. Ring the person.
4. Then do one of two things:
   - **Mark it done** if no further action is needed.
   - **Link to a case** if they already have one, so the contact is on the record. Open the case on the Cases tab first, come back, select **Link to a case** and type what they wanted.

Use the **Show** list to see calls already done, and **Days** to look further back.
