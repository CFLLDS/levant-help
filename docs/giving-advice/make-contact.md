# Make contact

There are three ways to reach a household from the advice file. The buttons are at the top of the file and again at the bottom of the Call tab.

## Phone: Contact

1. Select **Contact** (or **Contact via Teams**).
2. If a phone number is on file, Microsoft Teams opens in a new tab and dials it.
3. If there is no number on file, a box asks you to enter one. It is saved to the household and then dialled.

The portal **logs the call for you** the moment Teams opens, as "Outbound call via Teams", and counts it towards the funder total.

!!! warning "If nobody answers"
    The call is logged whether or not it connects. If you did not speak to anyone, add a **Note** on the Interactions tab saying so, for example "No answer, will try again Thursday", so the record is honest.

## Text: Check-in

A check-in is a short, friendly text asking whether the resident is keeping warm and well.

1. Select **Check-in** (or **Send check-in**).
2. A box shows the message. Read it. You can change the wording.
3. Select **OK** to send, or **Cancel** to stop. Nothing is sent until you select OK.
4. The portal confirms "Check-in sent and logged".

The check-in is counted under **Check-ins** on the Interactions tab.

**When check-in is switched off.** If the household has a red welfare flag the button is greyed out, with the reason beside it: the household needs a phone call, not a text. Use **Contact**.

Only text a resident who has agreed to be contacted that way. Check their preferred contact route on their case first.

## In person: Print / PDF

**Print / PDF** prints whichever tab you have open, tidied up for paper, or saves it as a PDF.

- Open the **Call** tab first to print a briefing to take on a visit.
- Open the **Evidence** tab first to print the evidence pack.

A printed advice file contains personal information. Carry it securely, do not leave it in the home, and shred it afterwards.

To book the visit itself, see [Book a visit](../households-and-visits/book-a-visit.md).
