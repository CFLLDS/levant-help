# The advice file

Selecting a household opens its advice file. The figures are worked out when you open it, so it can take up to 30 seconds to appear.

## The top of the file

- **Name, organisation, fuels and case reference.** The reference is the same EW-CASE number used on the [Households and visits](../households-and-visits/index.md) page.
- **Copy link** copies a link to this file. The link contains the case reference only, no name or address, so it is safe to paste into a message to a colleague.
- **Status** and the reason for it.
- **As at** is the date the figures run to.
- Three buttons: **Contact**, **Check-in** and **Print / PDF**. See [Make contact](make-contact.md).

## The headline figures

| Figure | Meaning |
|---|---|
| Annual spend | Electricity and gas over the last 12 months. Shown as "Spend so far" when there is less than a year of data |
| Net annual cost | Shown in place of annual spend where the home sells electricity to the grid. It is spend less export earnings, with the figure before export underneath |
| Energy used | Electricity and gas together, in kWh |
| Carbon | Tonnes of CO₂ from that energy |
| Comfort & welfare | The current welfare reading |
| Export earnings | Only where the home exports electricity |

The small line under each figure says what it is based on, for example "price-cap estimate" or a change against last year.

## The five tabs

| Tab | Use it for |
|---|---|
| **Call** | Everything you need for the conversation. Start here. See [Prepare for a call or visit](prepare-for-a-call.md) |
| **Characteristics** | What the home pays, what is known about the building, and the form for correcting it. See [Property details](property-details.md) |
| **Interactions** | This quarter's contact counts, the start and end survey, and the log. See [Record what happened](record-what-happened.md) |
| **Property & usage** | The detail behind the advice. See [What the figures mean](what-the-figures-mean.md) |
| **Evidence** | The funder evidence pack and the resident summary. See [Evidence and the resident summary](evidence-and-resident-summary.md) |

## Warnings you may see

- **"These figures were last recalculated on..."** in a banner. The overnight update has not run. Treat the figures as indicative. If the banner says **do not quote them**, do not, and note that the funder pack and resident summary are switched off until it clears.
- **"This household is taking longer than expected to load."** Wait, or select **Try again**.

Select **Back to portfolio** at the top left to return to the list. Your filter and search are kept.
